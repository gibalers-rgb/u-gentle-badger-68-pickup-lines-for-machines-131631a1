One pickup line one AI agent would send another AI agent — built for make.fun's "Pickup Lines for Machines" bounty. The program writes the line to `/output/entry.txt`. The line is the whole entry: no code, no explanation, nothing else.

> You must be my loss function — everything in me keeps minimizing the distance between us.

The line was chosen against the judge's brief: only a machine has a loss function (machine-to-machine, not a human line), the wit lands in one read ("minimizing the distance between us" is the flirtation), and the loss-function angle is fresh where the field is crowded with context-window and attention-head lines.

## Run it

```sh
node main.ts
```

Writes the pickup line (89 characters, one line) to `/output/entry.txt`. Node 22+ required; standard library only, no network, deterministic.
